# Integrations

## Integration model

Integration
→ authentication
→ account/resource discovery
→ capabilities
→ tools
→ events
→ permissions

## Examples

- Google
- GitHub
- Slack
- Discord
- Notion
- Microsoft
- Dropbox
- browser
- local filesystem

## Security

Each integration must declare:
- permissions
- scopes
- credentials
- data access
- actions

Never assume an OAuth token grants permission for every action.
