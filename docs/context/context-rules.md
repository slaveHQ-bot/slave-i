# Context Layering Strategy

Agents must progressively discover information to prevent context bloat:

- **L0 System rules**: Read GLOBAL_RULES.md.
- **L1 Agent role**: Read your specific role SKILL.md.
- **L2 Current task**: Read the assigned goal.
- **L3 Relevant architecture**: Consult docs/architecture/.
- **L4 Relevant files**: Read only files strictly necessary for implementation.
- **L5 Relevant history**: Consult docs/decisions/.
- **L6 Tool output**: Maintain strict compaction on logs.
