# Slave Product Vision

## Vision

Make Slave the most capable personal AI operating system for people who want AI to perform real work on their computer.

## Positioning

Slave is not primarily a chatbot.

It is a local-first execution system where the user gives an outcome and Main Slave coordinates a team of specialized Slaves to achieve it.

## Product promise

> Tell Slave what you want. Slave figures out how.

## Long-term capabilities

- persistent personal context
- memory
- personalization
- workflow learning
- multi-agent teams
- parallel execution
- browser automation
- computer control
- filesystem operations
- terminal
- integrations
- MCP
- plugins
- BYOK
- local models
- model routing
- permissions
- verification
- scheduling
- long-running tasks
- marketplace

## Strategic moat

Do not compete primarily on model intelligence.

Build moat around:
- personal context
- memory
- capabilities
- execution
- permissions
- integrations
- agent collaboration
- verification
- local-first state
