# Slave Product Principles

1. User asks for outcomes, not implementation details.
2. Main Slave orchestrates.
3. Specialized Slaves execute.
4. Local-first is the default.
5. BYOK keeps models replaceable.
6. Memory should make Slave increasingly useful.
7. Learning must be transparent and reversible.
8. Permissions must be enforceable at execution boundaries.
9. Parallelism should reduce completion time.
10. Verification should reduce false success.
11. The UI should hide unnecessary complexity.
12. Advanced users should be able to inspect everything.
13. Do not optimize for demos at the expense of reliability.
14. Do not build infrastructure before the product requires it.
15. Every architectural decision should be explainable.
