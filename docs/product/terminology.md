# Slave Terminology

## Slave

A specialized execution agent.

## Main Slave

The central persistent orchestrator that coordinates work.

## Agent

Generic technical term for Main Slave or a specialized Slave.

## Task

A unit of work with an objective and lifecycle.

## Conversation

A user interaction surface. Conversations can create one or more tasks.

## Run

One execution attempt of a task.

## Tool

An executable capability exposed to a Slave.

## Capability

A permissioned ability such as filesystem.read or browser.navigate.

## Integration

A connection to an external system/account/service.

## Memory

Persisted information intended for future relevant use.

## Context

Information assembled for a specific model/agent execution.

## Plan

A proposed strategy for completing a task.

## Task Graph

The dependency graph of subtasks.

## Artifact

A file or structured output produced during execution.

## Verification

Evidence or checks used to determine whether an output/result is trustworthy.

## Main principle

Users request outcomes. Main Slave chooses implementation.
