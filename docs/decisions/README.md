# Architecture Decision Records

Use ADRs for decisions that materially affect architecture.

Create an ADR when changing:
- storage
- agent lifecycle
- model/provider abstraction
- memory architecture
- permissions
- IPC/security boundaries
- task execution
- plugin/MCP model
- synchronization
