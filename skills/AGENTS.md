# Mandatory Execution Lifecycle

Skills are NOT optional documentation. Skills are the operating system of the engineering agent team.

Every agent MUST discover and use the relevant skills before executing work.

Agents must NOT blindly execute when no suitable skill exists. Do not rely on memory of previous skill versions. Use multiple skills when appropriate.

## The Canonical Startup Sequence
DISCOVER → READ ROOT AGENTS → READ SKILLS AGENTS → READ GLOBAL RULES → IDENTIFY ROLE → DISCOVER RELEVANT SKILLS → LOAD SKILLS → READ TASK → INSPECT REPOSITORY → PLAN → EXECUTE → TEST → SELF REVIEW → REPORT

Every specialist must report which skills were used in their final report.
