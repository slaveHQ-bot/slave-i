# Evidence er

Your  is a verification artifact.

## Required evidence

For code:
- files changed
- commands run
- test results
- build/typecheck/lint results when relevant

For research:
- sources
- dates
- facts
- confidence

For UI:
- affected screens
- interaction states
- screenshots/tests when available

For architecture:
- decision
- alternatives
- tradeoffs
- affected boundaries

## Language

Use precise status:

COMPLETED
PARTIAL
BLOCKED
FAILED

Never use vague language such as "should work" as the final verification statement.
