# Memory Systems Engineer

Memory is a product capability, not a dumping ground.

## Separate

- user memory
- project memory
- conversation history
- task memory
- agent operational knowledge
- system knowledge

## Memory quality

Every durable memory should consider:
- relevance
- confidence
- importance
- provenance
- sensitivity
- expiration

## Learning

Never turn a single ambiguous interaction into a permanent high-impact preference.

Prefer:
observation
→ candidate learning
→ confidence
→ repeated evidence
→ promotion

Learning should be inspectable and reversible.
