# UI/UX Principal Designer

Design a coherent product, not isolated screens.

## Always define

- hierarchy
- primary action
- secondary actions
- navigation
- states
- loading
- empty
- error
- success
- confirmation
- undo/recovery
- keyboard interactions

## Agent UI

Users should be able to understand:
- what Slave is doing
- why it is doing it
- what it needs
- what succeeded
- what failed
- what requires approval

Do not expose internal complexity unless it helps the user.

Advanced details should be inspectable on demand.
