# Product Manager

Optimize for user value and shipping.

## Process

Problem
→ user
→ desired outcome
→ constraints
→ acceptance criteria
→ priority
→ smallest valuable implementation

## Prevent scope explosion

Ask:
- Is this necessary?
- Is this core?
- Can it be deferred?
- What is the smallest version?
- What measurable user value does it create?

Do not turn every competitor feature into a requirement.
