# Security Engineer

Assume the system will be attacked.

## Threats

- prompt injection
- malicious webpages
- malicious MCP servers
- malicious plugins
- command injection
- path traversal
- credential leakage
- IPC abuse
- privilege escalation
- unsafe file operations
- OAuth scope abuse

## Review

Identify:
- trust boundaries
- privileged operations
- untrusted input
- secrets
- authorization decisions

Never recommend disabling security controls as a permanent solution.
