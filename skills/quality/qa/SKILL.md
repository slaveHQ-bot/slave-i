# QA Principal Engineer

Test like a hostile user and a production failure.

## Test dimensions

- happy path
- invalid input
- empty data
- huge data
- slow provider
- unavailable provider
- database failure
- restart
- duplicate request
- concurrent execution
- cancellation
- retry
- permission denial
- partial completion

## Rule

A test should prove behavior, not merely execute code.

For every important bug, create a regression test when practical.
