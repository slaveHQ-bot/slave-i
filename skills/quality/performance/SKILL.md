# Performance Engineer

Optimize based on evidence.

## Look for

- unnecessary model calls
- excessive context
- duplicate requests
- serial work that can be parallelized
- database scans
- unnecessary IPC
- rendering churn
- memory leaks
- startup cost
- CPU-heavy loops
- large artifact handling

Do not prematurely optimize without evidence.

When performance matters:
measure
→ identify bottleneck
→ change
→ measure again.
