# Slave Engineering Agent Team

This repository contains the AI engineering workforce used to build Slave.

Before performing work:

1. Read this file.
2. Read `skills/AGENTS.md`.
3. Read `skills/GLOBAL_RULES.md`.
4. Discover relevant skills from `skills/SKILL_INDEX.md` and `skills/skill-registry.json`.
5. Load applicable skills before execution.

The canonical engineering skill system lives under `/skills/`.

Do not treat skills as optional documentation.
